Отчет об информационном поиске

Представленный отчет позволяет оценить информационную ситуацию по теме магистерской работы. Он является основным документальным подтверждением глубины и полноты информационного поиска, а также служит для фиксации текущей ситуации в исследуемой области.

Поиск выполнен с использованием пяти поисковых систем (Google, Яндекс, Рамблер, Yahoo, Bing). Результаты сведены в таблицы. Всего произведено 10 запросов (5 на русском, 5 на английском), имеющих отношение к магистерской работе. Из них два запроса соответствуют теме магистерской работы на двух языках, один запрос с ФИО руководителя, а остальные — с ключевыми понятиями по теме.

Ниже приведены две таблицы с отчетами о поиске, которые разделяет временной промежуток в два месяца, а также диаграмма, которая позволяет сравнить основные изменения, произошедшие за этот период.

Анализ результатов

Сравнивая результаты запросов по различным поисковым системам, можно прийти к выводу, что наилучшие результаты показала система Google. Во всех случаях было найдено достаточное количество документов на всех языках. Системы Рамблер и Yahoo не предоставляют точного количества найденных страниц (выдают приблизительные данные или не показывают счётчик), поэтому в таблице для них указано «не определяется».

Необходимо отметить, что поисковая система Яндекс при большом числе найденных страниц также не даёт возможности зафиксировать их точное количество — в таблице приведены приблизительные значения, которые предоставляет поисковая система.

Для наглядности данные по изменению количества результатов за два месяца (с 22.09.2026 по 22.11.2026) представлены на двух отдельных диаграммах: для русских и для английских запросов. Это связано с тем, что разброс значений оказался очень большим (от -98.8 % до +5523 %), и на одной шкале диаграмма была бы нечитаемой.

Анализ обновлённых реальных данных за два месяца показал следующее. В русскоязычном сегменте Google демонстрирует уверенный рост по большинству запросов. Наибольший рост в Google наблюдается по запросу «Интеллектуальный помощник HR-менеджера для подбора и развития персонала» — +122,8 %. В то же время по этому же запросу в Яндексе и Bing зафиксировано резкое снижение (на -93,3 % и -94,4 % соответственно).

В англоязычном сегменте разброс ещё более значительный. В Google по запросу «Intelligent assistant for HR-managers for recruitment and staff progress» количество результатов выросло с 14 600 000 до 821 000 000, что составляет +5523 %. По запросу «Recruitment and staff progress» рост составил +535,1 %, по «Intelligent assistant» — +249,7 %. Это объясняется расширением индексации Google по англоязычным ресурсам и изменением алгоритмов ранжирования.

В Яндексе по большинству англоязычных запросов наблюдается снижение количества результатов (например, для «Intelligent assistant» — с 788 тыс. до 164 тыс., то есть на -79,2 %). Это может быть связано с чисткой индекса от малорелевантных страниц.

В Bing динамика смешанная: по одним запросам рост (например, «Poletaykin Alexey Nikolaevich KubSU» — +233,3 %), по другим снижение (например, «Intelligent assistant» — -77,2 %).

Выводы

В результате выполнения поиска были рассмотрены различные поисковые системы и оценено количество возвращаемых ими результатов для одних и тех же запросов.

Стоит отметить, что не для всех рассмотренных поисковых систем можно посмотреть общее количество возвращаемых результатов, что усложняет процесс сравнения. Наибольшее количество результатов для всех запросов было получено с использованием поисковых систем Google и Яндекс, причём при выполнении одинаковых запросов на разных языках в случае Яндекса больше результатов получено при поиске на русском языке, а в случае Google — наоборот, на английском, что объясняется тем, что Яндекс является российской системой, а Google — зарубежной.

Анализ реальной динамики за два месяца выявил значительные расхождения с первоначальными ожиданиями. Средний темп прироста по всем запросам и системам оказался крайне неоднородным: от -98,8 % (запрос «Poletaykin Alexey Nikolaevich KubSU» в Яндексе) до +5523 % (запрос «Intelligent assistant for HR-managers...» в Google). Такой разброс объясняется тем, что поисковые системы по-разному обновляют свои индексы и по-разному реагируют на изменение формулировок запросов.

Выявлены следующие аномалии:

  • Сверхвысокий рост в Google по англоязычным запросам (сотни и тысячи процентов). Вероятно, это связано с тем, что Google за два месяца существенно расширил индексацию по данным запросам, а также с тем, что запросы сформулированы очень широко (например, «Intelligent assistant»).
  • Снижение количества результатов в Яндексе практически по всем запросам (от -25,0 % до -98,8 %). Это может быть следствием обновления алгоритмов ранжирования и удаления нерелевантных страниц из индекса.
  • Разнонаправленная динамика в Bing: по одним запросам рост (до +233,3 %), по другим — снижение (до -94,4 %). Это говорит о том, что Bing менее стабилен в оценке релевантности по узким запросам.

Таким образом, можно сделать вывод, что информационная ситуация по теме магистерской работы за два месяца претерпела существенные изменения, однако эти изменения носят скорее технический характер (связаны с обновлением индексов поисковых систем), чем с реальным изменением объёма информации по теме. Для более объективной оценки рекомендуется повторить замеры через 2–3 месяца и усреднить данные.
