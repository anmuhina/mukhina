Комбинированная ML-модель оценивания образовательного потенциала вуза для задачи целевого подбора персонала

Авторы: А.Н. Полетайкин, А.А. Мухина

Описание: Рассматривается задача оценивания образовательного потенциала вузов для целевого подбора персонала. Предлагается комплексный подход, включающий линейную аддитивную модель на основе экспертных весов и классические методы машинного обучения. Разработан программный модуль на Python, реализующий генерацию исходных данных, расчёт образовательного потенциала, ранжирование вузов и сравнительный анализ на основе коэффициента ранговой корреляции Спирмена.
